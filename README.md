# 쿠팡 소싱 탐색기 — GitHub 통합 업데이트

생활용품 카테고리 적합도 사전 필터 → 카테고리 랭킹 40개 분석(허용된 CSV) → 메인키워드 발굴 → 불사자/쿠팡 검색 1P 파일 분석.

## 가장 간단한 사용법

- **처음 설치:** 이 저장소의 Code → Download ZIP으로 내려받아 새 폴더에 압축 해제 후 `START.bat` 실행.
- **기존 설치에서 업데이트:** 새 버전 설치 시 기존 `app_data` 폴더만 새 폴더로 복사. 이후부터는 `UPDATE.bat` 한 번으로 전체 프로그램 버전을 맞춘 뒤 실행.
- **나중에 업데이트:** `UPDATE.bat` 더블클릭. GitHub 저장소의 `main`에서 모든 프로그램 파일을 한 번에 내려받아 SHA256 검증 후 적용.
- 기존 자동 실행을 설정했다면 PC 로그인 시 `START.bat`가 실행됨. 업데이트는 필요할 때만 `UPDATE.bat` 실행.

**중요:** `app_data`, `.venv`, `logs` 폴더는 GitHub 업데이트에서 제외하고 보존합니다. 변경된 코드는 `app_data/code_backups`에 백업합니다.

GitHub는 프로그램 **코드**의 저장소입니다. 쿠팡 Access/Secret Key, 실적, 사업자 정보 등 민감한 데이터는 공개 GitHub에 업로드하지 마세요. 저장소는 현재 공개 저장소이므로 특히 주의해야 합니다.

쿠팡 검색 페이지 실시간 자동 수집은 외부 환경에서 HTTP 403으로 **검증되지 않았습니다**. 승인된 상품 자료 업로드 분석 기능과 혼동하지 마세요.
